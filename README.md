# Физический прогресс

Веб-приложение для преподавателя физической культуры УрТИСИ СибГУТИ.

## Что делает приложение

- Учет студентов и их групп
- Ведение результатов тестов по датам и единицам измерения
- Создание и редактирование ведомостей
- Импорт и экспорт данных в Excel (.xlsx)
- Раздел ГТО для выбора ступени и пола, с возможностью сохранения результатов
- Сохранение данных локально в браузере через localStorage

## Как запустить

1. Откройте папку проекта.
2. Запустите локальный сервер:

```bash
python -m http.server 8000
```

3. Перейдите в браузер по адресу:

```text
http://localhost:8000
```

## Структура проекта

- `index.html` — структура интерфейса
- `styles.css` — стили в минималистичном темно-синем и белом оформлении
- `app.js` — логика учета, таблиц, Excel и сохранения данных

## Примечание по ГТО

Для официальных нормативов ГТО используются данные из официального источника gto.ru и приказов Минспорта РФ. В интерфейсе результат ГТО сохраняется и может быть проверен после импорта актуальных нормативов; точные численные пороговые значения не подставляются без подтверждения официальной таблицы.

## Данные

Все данные хранятся в браузере, поэтому приложение работает без сервера и регистрации.

## Импорт/экспорт Excel

Импорт и экспорт реализованы через библиотеку SheetJS. Для корректной работы требуется подключение к интернету для загрузки библиотеки с CDN.
